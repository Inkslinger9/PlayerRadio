# Player Radio (PEAK mod)

Every player gets their own radio that plays their own music from their character in 3D, and everyone in the lobby hears everyone's radio. A BepInEx 5 plugin for PEAK.

- Players: install from Thunderstore (r2modman / Gale). The full player guide is in [`thunderstore/README.md`](thunderstore/README.md), and the version history is in [`thunderstore/CHANGELOG.md`](thunderstore/CHANGELOG.md).
- Thunderstore package files (manifest, icon, README, changelog) are in `thunderstore/`.

## Building
Requirements: the .NET SDK (6 or newer) and PEAK with BepInExPack_PEAK installed. The project references the game's own assemblies and BepInEx from your game folder; **no game or BepInEx DLLs are included in this repository, and none should be committed.**

1. Tell the build where PEAK is installed (`GameDir`), in one of these ways:
   - Copy `GameDir.props.example` to `GameDir.props` (git-ignored) and set the path inside, or
   - pass it on the command line: `dotnet build -c Release -p:GameDir="D:\SteamLibrary\steamapps\common\PEAK"`.
   - If `GameDir` isn't set, `C:\Program Files (x86)\Steam\steamapps\common\PEAK` is used when it exists.
2. Build: `dotnet build -c Release`
3. The plugin is written to `bin/Release/PlayerRadio.dll`. Copy it to `BepInEx/plugins/PlayerRadio/` in your game or mod-manager profile.

`GameDir` must contain `PEAK_Data/Managed` (game and Unity assemblies) and `BepInEx/core` (`BepInEx.dll`, `0Harmony.dll`).

## Thunderstore package
Zip these files at the root of the archive: `thunderstore/manifest.json`, `thunderstore/README.md`, `thunderstore/CHANGELOG.md`, `thunderstore/icon.png` and the built `PlayerRadio.dll`.
